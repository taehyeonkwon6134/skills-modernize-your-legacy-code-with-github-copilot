# COBOL Account Management Test Plan

This plan characterizes the current COBOL application for business stakeholder review and as a basis for Node.js unit and integration tests. It covers one in-memory account balance, initialized to `1000.00` each time the application starts. The current application has no student records, student identifiers, multiple accounts, transaction history, or persistent storage; student-specific rules cannot be validated until those capabilities are defined and implemented.

Run each case in a fresh application process unless its pre-condition says to continue an existing session. Record observed behavior in **Actual Result**, then set **Status (Pass/Fail)** after stakeholders agree that the expected behavior is acceptable. Cases marked as characterization require a business decision before they can become normative pass/fail tests.
